# V6.1.0 — Signature art direction · premium visual polish

## Visual improvements
- **Section transitions:** hard dark↔light stops replaced with 6rem gradient seams that overlap the outgoing room,
  creating a designed transition instead of an arbitrary colour change.
- **Hero depth:** system diagram uses three opacity layers (background 0.08 paths, midground 0.7 core, foreground
  0.85 nodes), with unrelated nodes dropping to 0.5 on hover — depth without 3D.
- **Photo hover:** desktop images scale 1.012 on hover (600ms ease), disabled on touch and under reduced motion.
- **Photo metadata:** "KrisLynx / Workspace · Nandyal" annotation on the workspace photo (mono, 70% white, no
  fabricated camera data).
- **Scroll reveal choreography:** heading → supporting text → visual, staggered at 80ms intervals (motion-gated;
  total ≤ 640ms).
- **Footer typography:** brand name at `--type-title`, tagline at `--type-small`, groups at `--type-small`, legal at
  `--type-micro` — deliberate hierarchy.
- **Visual quiet:** section metadata dimmed to 0.7; the display heading is always the dominant element.

## UX improvements
- CTA buttons: arrow micro-interaction (3px translateX on hover, no bounce).
