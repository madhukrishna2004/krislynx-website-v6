# V5.1 — Final production excellence + visual QA · 27 Sep 2026

## 1. Executive summary
Offline, V5.1 is the cleanest build of the site: the intermittent Technology CLS is fixed at its root, three
guard tests that could not previously prove themselves now do, the full suite passed twice without a flake, and every
remaining status label found by a full sweep is gone. **Release recommendation: ready to deploy; NOT yet verified as
production-ready** — cross-browser, real-device, live-domain, contact-delivery and Search Console checks require the
owner's environment and have not been run (§7, §8, §14–16).

## 2. Changes made
- Sticky header keeps identical layout height in its compact state (was 58→51.6px).
- JS-only controls (⌘K button, architecture trace) are `inert` until activated — laid out from first paint, not
  focusable, hidden from assistive tech; JS-dependent layout also applies via `@media (scripting: enabled)`.
- Duplicate-content guard rewritten as a pure function (`src/lib/content-guards.ts`) with fixtures + mutation test.
- Repetition removed: module descriptions repeated up to 3× on the EduLynx page/homepage; repeated contact sentence.
- Navigator: every destination mapped onto the six required groups (Recent · Products · Technology · Engineering ·
  Company · EduLynx modules); /technology was mis-grouped under Company.
- Assistant: Products-page context added.
- Status labels removed from: case-study Status row and Type field (3 case studies), /industries "(internal project)",
  /company legacy ecosystem diagram + legend (replaced by the label-free product system); dead component + CSS removed.

## 3–4. Bugs discovered → fixed
| Bug | Root cause | Fix |
|---|---|---|
| Technology CLS 0.016 in 4/10 loads | (a) ⌘K button revealed after first paint — **the V5 "space reservation" never worked: base.css `[hidden]{display:none !important}` overrode it** (V5's reported fix was based on lucky runs); (b) `.js` class added by a deferred script, so first paint sometimes used the no-JS architecture layout | `inert` controls + `scripting: enabled` twins → 0/10 runs > 0.005 (max 0.0032) |
| Header compact state changed layout height | `.site-header__bar` min-height reduced on scroll | removed; compactness via width/surface/border |
| Duplicate guard could pass with an injected duplicate | `<p[^>]*>` matched SVG `<path>` | real-`<p>` pattern; proven by fixtures + mutation test |
| Repeated module descriptions / contact sentence | content | removed (guard now also detects repeated paragraphs) |
| Navigator put /technology under Company | page group | explicit six-group mapping |
| Status wording in metadata/legend/types | V2–V4 sweeps checked prose, not metadata | removed + guard over metadata/legends/types |
