# V6.0.0 — Signature digital experience · visual excellence transformation

## Visual changes
- **Hero:** subtle technical grid background (radial-masked, ≤ 2.5% opacity), "System / 01 · Architecture / Active"
  metadata, substantially more vertical breathing room (7vh min → 10vh desktop).
- **Photography:** workspace and company photos break containers on desktop (editorial feel); full-bleed utility for
  edge-to-edge phone images. Workspace gets 21:9 cinematic crop on desktop, 16:9 on tablet.
- **Section transitions:** thin shared rule bridges dark↔light rooms.
- **Buttons:** three tiers — solid primary, outline secondary, text+arrow tertiary.

## UX changes
- **Pixel refinement (§49):** consistent button min-heights (2.75rem / 3.25rem lg), consistent tlabel mono styling,
  consistent section padding (6rem phone → 7.5rem desktop), comfortable 1.25rem mobile gutters.
- **Mobile (§50):** hero text-first composition with compact diagram below (not shrunken desktop); products vertical
  storytelling; flagship always full-width.
- **Tablet (§51):** 768–1024 gets its own hero grid (2-col, aligned), own architecture layout (single column), own
  workspace crop, own product grid (2-col with full-width flagship).
- **Motion (§52):** idle hero glow removed — system diagram becomes still when not interacting; hover activates it.

## Typography
- Responsive hero sizes defined as tokens (`--type-hero-sm`, `--type-hero-md`) alongside the 11-role scale.
- Mobile meta label uses the `--type-micro` token (was a literal `10px` — caught by the freeze test).

## Photography
No new photos; existing enhanced workspace, meeting room, corridor, signage and server room unchanged.
